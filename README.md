# E-Commerce Sales & Inventory Analytics Dashboard

## 📌 Project Overview

The E-Commerce Sales & Inventory Analytics Dashboard is an interactive business analytics project developed using **Microsoft Excel**.
The project analyzes e-commerce transaction data to understand sales performance, revenue trends, product performance, profitability, and inventory status.
The dashboard converts raw transactional data into meaningful business insights using Excel data analysis and visualization techniques.

## 🎯 Objectives

- Analyze e-commerce sales transactions
- Track monthly revenue trends
- Identify top-performing products
- Compare revenue across product categories
- Calculate total revenue and profit
- Monitor inventory stock levels
- Identify low-stock orders
- Create an interactive and visually appealing dashboard

## 📊 Dataset

The dataset contains **500 e-commerce transactions**.

The main fields include:

- Order ID
- Order Date
- Product ID
- Product Name
- Category
- Quantity
- Unit Price
- Cost Price
- Revenue
- Profit
- Customer Name
- Region
- Payment Method
- Stock Available
- Stock Status

## 🔧 Data Processing

The raw transaction data was cleaned and organized before creating the dashboard.

### XLOOKUP

XLOOKUP was used to retrieve product information from the Product Master table, including:

- Product Name
- Category
- Unit Price
- Cost Price

### Revenue Calculation

```text
Revenue = Quantity × Unit Price
````

### Profit Calculation

```text
Profit = Revenue - (Quantity × Cost Price)
```

### Stock Status

Inventory records were categorized into:

* LOW STOCK
* OK

Conditional formatting was used to highlight low-stock records.
