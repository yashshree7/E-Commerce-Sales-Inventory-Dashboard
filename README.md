# E-Commerce Sales & Inventory Analytics Dashboard

## 📌 Project Overview

This project is an interactive E-Commerce Sales & Inventory Analytics Dashboard developed using Microsoft Excel.

The dashboard analyzes transactional e-commerce data to provide insights into sales performance, revenue trends, product performance, profitability, and inventory status.

## 🎯 Objectives

- Analyze e-commerce sales data
- Track monthly revenue trends
- Identify top-performing products
- Compare revenue across product categories
- Monitor inventory levels
- Identify low-stock orders
- Create an interactive business dashboard

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- XLOOKUP
- Excel Formulas
- Conditional Formatting
- Pivot Charts
- Data Visualization

## 📊 Dataset

The dataset contains 500 e-commerce transactions.

The data includes:

- Order ID
- Order Date
- Product ID
- Product Name
- Category
- Quantity
- Unit Price
- Cost Price
- Revenue
- Profit
- Customer Name
- Region
- Payment Method
- Stock Available
- Stock Status

## 📈 Dashboard Features

### 1. Monthly Revenue Trend

Shows revenue performance across January to December.

### 2. Revenue by Product Category

Compares revenue generated by:

- Electronics
- Fashion
- Home

### 3. Top Performing Products

Shows revenue generated by individual products.

### 4. Inventory Stock Status

Displays the number of:

- LOW STOCK
- OK

orders.

### 5. KPI Dashboard

The dashboard displays:

- Total Revenue
- Total Profit
- Total Orders
- Low Stock Orders
